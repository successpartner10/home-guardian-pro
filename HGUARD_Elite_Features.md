# HGUARD Elite — Tactical Surveillance Ecosystem

HGUARD Elite is a professional-grade, web-native security platform that transforms any device into an intelligent surveillance node.

---

## ⚡ Core Architecture & Privacy
- **Strict Data Isolation** — 100% privacy between accounts. User A cannot see User B's cameras or recordings.
- **Siloed Cloud Storage** — Recordings are saved directly to your private Google Drive; HGUARD never stores your video on its servers.
- **Snappy Performance** — Memoized React components and sub-200ms UI transitions for elite responsiveness.
- **Slide-out Tactical Drawers** — Ergonomic control drawers that maximize video visibility while keeping all tools one tap away.
- **Gatekeeper Security** — Admin-gated platform access prevents unauthorized nodes from joining the mesh.

---

## 👁️ Advanced Vision & Sensing
- **Bridge Mode** — Import Ring, Nest, Arlo, and Zoom feeds via secure browser-tab bridging.
- **Tactical Night Vision Boosting** — Automatic low-light digital amplification with AI high-sensitivity scene awareness.
- **Hardware Source Selector** — Hot-swap between phone lenses, USB webcams, and virtual camera inputs.
- **AI Smart Zoom** — Keep the picture sharp and vector-accurate even when you zoom in deep.
- **Privacy Zones** — Tell HGUARD to ignore movement in certain areas (like trees or a busy street).

---

## 🤖 AI Features & Labs
- **AI Thermal Reconstruction** *(Active)* — Neural heat-map overlay reconstructed from standard IR/night-vision sensor data. Identifies human heat signatures in total darkness.
- **Cross-Camera Mesh Object Tracking** *(Active)* — Cooperative multi-node target lock. Automatically hand-offs tracking between adjacent cameras as a subject moves through the property.
- **Predictive AI Threat Guard** *(Research)* — Calculates a live threat quotient score by analyzing lingering duration, approach vectors, and proximity danger zones. Alerts only on genuinely suspicious behavior.
- **Autonomous Security Siren** *(Research)* — Triggers high-decibel audible siren and strobe flash deterrence when the AI Threat Guard locks on a persistent high-risk target.
- **AI Behavioral Anomaly Detection** *(Lab Proposal)* — Learns your household's normal daily patterns and alerts only on genuine deviations.
- **Edge Facial Recognition** *(Lab Proposal)* — On-device face classification to distinguish family members from unknown visitors without cloud upload.
- **Natural Voice Control** *(Lab Proposal)* — Ask HGUARD conversational questions: "Is the front door open?", "When did the mail carrier arrive?"

---

## ☁️ Elite Storage & Playback
- **Elite Archive** — Review and play back recorded clips directly within the app via Google Drive blob streaming.
- **Drive Quota Control** — User-defined GB limits with FIFO (First-In, First-Out) automatic clip recycling.
- **Smart Recording** — HGUARD only saves important motion-triggered events, ignoring idle frames to save storage space.
- **Direct Downloads** — Download high-quality .webm security clips directly from the archive page.

## 🌐 Deployment & Tech Stack
- **Framework**: React + Vite (TypeScript)
- **Database**: Firebase Firestore (Real-time NoSQL)
- **Streaming**: WebRTC (P2P Encryption, STUN/TURN)
- **Cloud Storage**: Google Drive API v3
- **AI Engine**: Gemini Pro Vision / Gemma (Edge + Cloud Orchestration)
- **Hosting**: Firebase Hosting with global CDN edge
- **Mobile**: Capacitor (Android/iOS native wrapper)
